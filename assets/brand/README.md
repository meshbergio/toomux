# toomux refined brand kit v3

This pack rebuilds the approved refined toomux identity as production vectors.

## Identity
- Figure-eight mark: smooth Bézier reconstruction of the approved broken-loop symbol with the two intentional line breaks intact.
- Wordmark: vector silhouette reconstructed directly from the approved reference, preserving its one-sided `t`, compact circular `oo`, rounded `m/u`, broad `x`, spacing and vertical alignment.
- Palette: Graphite `#121619`, Ivory `#F6F5F1`, Mint `#57E6BE`, Slate `#687178`.

## Primary lockup proportions
- mark height: 174 units
- wordmark height: 157 units
- gap: 44 units
- mark is deliberately ~11% taller than the wordmark, matching the reference.

## Production rules
- Use the primary graphite lockup on light backgrounds.
- Use the reversed Mint + Ivory lockup on Graphite.
- Do not reconnect the figure-eight line breaks.
- Do not add glows, gradients, shadows, terminal symbols or network-node motifs.
- Production SVGs contain paths only and require no fonts.
